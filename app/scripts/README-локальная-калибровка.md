# Калибровка для личных проверок — только на этой машине

Решение владельца (#439): порт калибровки Sibionics из JugglucoNG нужен **лично ему** —
для сверки в реальном времени и часовых проверок на телефоне. **В публичное не уходит
никогда.**

Что это значит на практике:

- каталог `app/android/app/src/main/java/ru/imiron/sugarlife/vendor/` **не попадает в git**
  и не попадает в APK, который мы публикуем в релизах;
- перед сборкой релиза CI проверяет, что чужого кода в дереве нет, и валит сборку, если он
  появился (`.github/workflows/android.yml`). Проверка стоит до сборки намеренно: релиз с
  чужой лицензией отозвать нельзя — его уже скачали;
- то же самое стережёт тест `app/src/чужойКод.test.ts` — он ловит и переименованный
  каталог, по строке лицензии в шапке файлов.

## Как собрать себе, с калибровкой

```bash
bash app/scripts/fetch-vendor-calibration.sh   # качает чужой код на эту машину
```

Дальше обычная сборка. Собранное так приложение — **личное**: как только оно уедет кому-то
ещё, включая тестировщика, приложение целиком обязано стать GPL-3.0 с открытыми
исходниками. Это не наша строгость, это условие лицензии.

## Почему не в репозитории

Приложение публикуется под MIT, APK лежит в релизах и ставится с телефона — это передача
программы другому человеку в самом обычном смысле. Совмещение с GPL-3.0 в таком виде
означает, что под GPL обязано уйти всё приложение.

Однажды это уже случилось: двадцать две тысячи строк доехали до опубликованного APK внутри
коммита про уведомления. Заметили через сутки, на ревью следующего PR.
