# 0001. PWA-приложение из дизайн-хэндофа на своём мини-движке

Статус: принято
Дата: 2026-07-29

## Контекст

Пришёл высокодетальный дизайн-хэндоф (`design/handoff/`): 5 экранов + 18 шторок,
финальные токены (дизайн-система Nocturne), вся логика приложения. Хэндоф собран как
`.dc.html`-прототип с проприетарным рантаймом `support.js` (генерируется из React-рантайма
дизайн-инструмента) и рамкой `ios-frame.jsx`.

Нужно было начать делать приложение и развернуть на GitHub Pages в текущей фазе проекта —
HTML-прототипы без сборки и без фреймворков (см. `CLAUDE.md`).

README хэндофа рекомендует не переносить HTML/JS прототипа, а воспроизвести экраны
в целевом нативном стеке. Но нативный стек ещё не выбран, а фаза проекта — HTML.

## Рассмотренные варианты

- **A. Отдать прототип как есть** (React + `support.js` + рамка телефона). Быстро, но:
  ставит проприетарный рантайм в продукт (README прямо не рекомендует), тянет React,
  показывает «телефон на столе», а не устанавливаемый PWA.
- **B. Переписать всё вручную нативно.** Соответствует README, но нативный стек не выбран,
  а объём (≈2600 строк разметки + логика) — большой риск дрейфа от пиксель-в-пиксель.
- **C. Переиспользовать разметку экранов и логику как спецификацию, но заменить рантайм
  своим компактным движком (~200 строк ванильного JS).** Без фреймворка, без сборки,
  офлайн — ровно под текущую фазу.

## Решение

Вариант **C**. В `prototypes/app/`:

- `engine.js` — свой рендер под диалект хэндофа: `{{ выражение }}`, `<sc-if>`, `<sc-for>`,
  события, псевдосостояния `style-hover/-active/-focus`, SVG-namespace, сохранение фокуса
  и каретки инпутов между ре-рендерами. Это НЕ `support.js`.
- `app.js` — состояние и вычисляемые пропсы (класс `Component`), воспроизведённые из
  хэндофа как спецификация поведения.
- `index.html` — оболочка PWA + токены Nocturne + инлайн-стили + встроенный шаблон тела.
- `manifest.webmanifest`, `sw.js`, `icons/` — устанавливаемость и офлайн.

Полный исходный хэндоф сохранён в `design/handoff/` как источник истины (не деплоится).

## Последствия

- Есть работающий устанавливаемый PWA на GitHub Pages уже в HTML-фазе, без сборки и
  фреймворков; тёмная/светлая тема, офлайн после первого захода.
- Токены и поведение зафиксированы кодом → ранняя проверка UX на реальном телефоне.
- Когда стек выберут, `design/handoff/` + `prototypes/app/` служат точной спецификацией
  для нативной пересборки (как и просит README хэндофа). Свой движок и разметку в натив
  не тащим — переносим дизайн и логику.
- Иконки Phosphor и шрифт Inter грузятся с CDN и кэшируются service worker'ом
  (офлайн после первого посещения). При желании — векторизовать локально позже.
