# SladkaЯ жизнь — PWA

Интерактивное приложение самоконтроля диабета 1 типа, собранное по дизайн-хэндофу
(`../../design/handoff/`). Чистый ванильный JS, без сборки и фреймворков, устанавливается
на телефон, работает офлайн.

## Экраны

Сегодня · Метрики · НМГ/МГ (мониторинг) · Инсулин · Профиль — плюс 18 шторок
(глюкоза, справочник инсулинов, уведомления, интеграции, экспорт, датчик, болюс, еда и др.).

## Как запустить локально

```bash
cd prototypes
python3 -m http.server 8000
# открыть http://localhost:8000/app/
```

Нужен HTTP-сервер (не `file://`) — из-за service worker и относительных путей.

## Устройство

| Файл | Назначение |
| --- | --- |
| `index.html` | Оболочка PWA: токены Nocturne, инлайн-стили, встроенный шаблон тела экранов |
| `engine.js` | Мини-движок рендера: `{{ }}`, `<sc-if>`, `<sc-for>`, события, hover/active/focus, SVG, сохранение фокуса инпутов |
| `app.js` | Состояние и вычисляемые пропсы (класс `Component`) — воспроизведены из хэндофа |
| `nocturne.css` | Токены дизайн-системы Nocturne |
| `manifest.webmanifest`, `sw.js`, `icons/` | Устанавливаемость и офлайн |

`engine.js` — своя реализация, а не проприетарный `support.js` из хэндофа. Разметка и
логика взяты как спецификация. Подробнее — `docs/decisions/0001-pwa-iz-dizajn-handofa.md`.
