# Handoff: мобильное приложение для человека с диабетом (iOS, 402×874)

## Overview
Мобильное приложение для самоконтроля диабета: непрерывный мониторинг глюкозы (НМГ) или глюкометр (МГ),
учёт еды и углеводов, доставка инсулина (помпа или шприц-ручка), метрики за период и профиль с настройками.
Интерфейс полностью на русском языке, тёмная тема по умолчанию, светлая тема поддержана.

## About the Design Files
Файлы в папке `design/` — **дизайн-референсы, собранные в HTML**. Это прототипы, показывающие
внешний вид и поведение, а не продакшн-код для копирования. Задача разработчика — **воспроизвести
эти экраны в существующей среде целевого проекта** (SwiftUI / React Native / Flutter / React),
используя её паттерны, навигацию и библиотеки. Если кодовой базы ещё нет — выбрать подходящий стек
и реализовать дизайн в нём. HTML/JS из прототипа не переносить.

Как открыть прототип: открыть `design/Приложение диабетика.dc.html` в браузере (нужны все файлы рядом,
включая `support.js`, `ios-frame.jsx` и папку `_ds/`). Клики, шторки и переключатели работают.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, радиусы, иконки и интеракции.
Воспроизводить пиксель-в-пиксель, подставляя компоненты целевой платформы.
Базовый холст — iPhone 402×874 pt (iPhone 16 Pro), safe-area сверху 72px (на экране «Сегодня»).

Не используются. Возвышение — заливка `--color-neutral-900` на `--color-bg` плюс граница `1px --color-neutral-800`

## Global structure

Каждый экран — колонка: **верхний блок** (фиксирован) → **скроллируемый контент** → **таб-бар** (фиксирован).
Шторки — `position: absolute; inset: 0` над контентом, поверх скрима.

### Верхний блок (общий для всех экранов)
Три элемента в строке: левое «крыло», центральный круг глюкозы, правое «крыло».

- **Круг глюкозы**: значение (44px/600), стрелка тренда справа, под ним единицы (12px, `--color-neutral-300`),
  ниже «3 мин назад» (11px, `--color-neutral-400`).
- **Левое крыло (НМГ)**: иконка волны, название датчика, «День 3 из 10» — счётчик дней сенсора.
- **Правое крыло (помпа)**: иконка помпы, название устройства, остаток инсулина в единицах + тип быстрого инсулина.
- Крылья кликабельны и ведут на соответствующие экраны (НМГ / Инсулин).

**Коллапс при скролле.** Блок имеет три состояния, значения интерполируются между ними:

| Параметр | «Сегодня» (full) | Другой экран, вверху | Другой экран, проскроллен (`scrollTop > 10`) |
| --- | --- | --- | --- |
| padding-top | 72px | 58px | 52px |
| высота строки | 150px | 92px | 54px |
| значение глюкозы | 44px | 27px | 17px |
| стрелка | 22px | 15px | 11px |
| иконка крыла | 24px | 17px | 15px |
| название | 14px | 12px | 11px |
| значение крыла | 15px | 14px | 12px |
| единицы | 12px | 9px | скрыты |
| раскладка крыла | column | column | row, gap 7px |
| подписи (день, «3 мин назад») | видны | скрыты | скрыты |

Переход — плавный (рекомендуется 180–220ms ease-out, привязанный к порогу скролла, без «дрожания»: порог 10px с гистерезисом).

## Screens

### 1. Сегодня (`today`)
**Назначение:** мгновенный ответ «какой у меня сахар сейчас и что происходит».
**Layout:** верхний блок в полном (full) состоянии → сетка плиток под ним, поля 20px, отступ снизу 24px.
- Плитки данных: карточка `border-radius: 20px`, фон `--color-neutral-900`, внутри — подпись 11px,
  значение 34px/600 + единица, иконка сущности в цвете `--c-*`, и на дне карточки — двухслойная
  SVG-«волна» (задний слой цветом `-2`, передний `-3`) как декоративный спарклайн.
- Форма волны отражает характер данных: плавная (глюкоза, инсулин, активность),
  почти плоская (в диапазоне), зубчатая (углеводы).
- Клик по круглому значению глюкозы открывает шторку «Глюкоза».

### 2. Метрики (`metrics`)
**Назначение:** статистика за период.
**Layout:** `padding: 20px`.
- Селектор периода (чипы).
- Переключатель метрики: `glucose` / углеводы / инсулин / активность — каждая со своим hero-значением
  (например «В диапазоне · 57 %»), иконкой и цветом.
- Ниже — плитки с сопутствующими показателями: средняя глюкоза, ст. отклонение, в диапазоне, углеводы, болюс, базал, активность, шаги.
- Фильтры слоёв графика (глюкоза / углеводы / инсулин / активность) — чипы с цветной точкой; каждый включает/выключает слой.

### 3. Мониторинг (`mon`) — НМГ или МГ
**Назначение:** управление источником данных о глюкозе.
Заголовок и содержимое зависят от `monitor` (`cgm` | `bgm`).

**Режим НМГ (`cgm`):**
- Раздел **«Датчики»** (uppercase 12px) + кнопка добавления.
- Карточка датчика: модель, серийный номер, дата установки, шеврон.
  У активного — прогресс-бар срока службы: трек `height: 5px, radius 3px, --color-neutral-800`,
  заполнение `--color-accent`. Данные датчика: день 3 из 10, сигнал «хороший», батарея 78%, место — «Левая рука».
- Клик по карточке → шторка «Датчик».

**Режим МГ (`bgm`):**
- Две кнопки в строку: «Синхронизация с глюкометром» и ручной ввод —
  `padding: 15px 12px`, `radius 18px`, `1px solid --color-accent`, фон — акцент @ ~12%.
- Напоминания об измерении (у глюкометра нет непрерывных данных).

### 4. Инсулин (`ins`)
**Назначение:** доставка инсулина и связанные настройки. Содержимое зависит от способа терапии.

- Переключатель способа: **Помпа** (`ph-drop-half`) / **Шприц-ручка** (`ph-syringe`) — чипы.
- **Помпа:** блок-кнопка «Управление помпой» (`ph-sliders`) → шторка «Управление помпой»;
  показатели: работа помпы, базальная скорость `0.9 ед/ч`, временный базал «выкл».
- **Шприц-ручка:** блок-кнопка «Напоминания о болюсе» (`ph-bell-ringing`) → соответствующая шторка;
  дополнительная строка «Базальный инсулин» (`ph-moon-stars`) → выбор длинного инсулина.
- Список настроек: быстрый инсулин (по умолчанию **Fiasp**), базальный (**Tresiba**) — открывают справочник инсулинов.
- Блок-кнопка: `width 100%`, `padding 16px`, `radius 18px`, `1px solid --color-neutral-700`,
  фон прозрачный, иконка 22px в акценте слева, шеврон справа.

### 5. Профиль (`profile`)
**Назначение:** настройки и данные пользователя.
**Layout:** `padding: 20px`, разделы с uppercase-заголовками, внутри — списки строк.
Разделы: **Терапия**, **Мониторинг**, **Интеграции**, **Внешний вид**, **Уведомления**, **Личные данные**.
- Строка списка: `padding: 14px 16px`, иконка 19px в акценте, заголовок 14px,
  значение 13px `--color-neutral-400` справа, шеврон `ph-bold ph-caret-right` 14px `--color-neutral-600`,
  разделитель `1px solid --color-neutral-800` (последняя строка — без).
- Список в целом: `border-radius: 18px; overflow: hidden; background: --color-neutral-900`.
- **Внешний вид:** три чипа темы — «Системная» (`ph-circle-half`), «Светлая» (`ph-sun`), «Тёмная» (`ph-moon`).
  Выбранный: фон акцент @26% на `--color-neutral-900`, граница акцент @65%, текст `--color-text`.

### 6. Дизайн-код (`ds`) — служебный экран
Внутренняя страница-каталог: поверхности, семантические цвета, типо-шкала, радиусы, примеры компонентов.
Дублируется отдельным файлом `design/Дизайн-код.dc.html`. В продакшн не входит — но задаёт значения,
которые нужно перенести в тему приложения.

## Sheets (bottom sheets)

Все шторки построены по одному шаблону:

- Контейнер: `position: absolute; inset: 0`, колонка, контент прижат к низу.
- Скрим: `--c-scrim` @58% + `backdrop-filter: blur(3px)`, клик закрывает шторку.
- Панель: фон `--color-bg` (списки внутри — `--color-neutral-900`), `border-radius: 26px 26px 0 0`,
  максимум ~92% высоты, внутренний скролл `padding: 12px 18px 26px`, скроллбар скрыт.
- Анимация появления: `@keyframes sheetUp { from { transform: translateY(101%) } to { translateY(0) } }`,
  ~260ms ease-out; скрим — `fadeIn`.
- **Единый заголовок:** название 19px/600 слева, кнопка закрытия справа.
- Z-порядок: базовая шторка `z-index: 40`, вложенные `41`, второй уровень `42`, единицы измерения `46`.

## Interactions & Behavior
- **Навигация:** таб-бар, 5 корневых экранов; переход сбрасывает открытые шторки и `scrolled`.
- **Шторки:** открытие снизу вверх (`translateY(101%) → 0`, ~260ms ease-out), скрим `fadeIn`.
  Закрытие — тап по скриму, кнопка закрытия или выбор значения в списке.
- **Коллапс шапки** — по `scrollTop > 10` (см. таблицу выше).
- **Выбор из списка** — тап по строке немедленно применяет значение и закрывает шторку (без кнопки «Готово»).
- **Степперы** — кнопки −/+ с клампом по границам и округлением до 0.1.
- **Чипы-фильтры** — одиночный выбор; **слои графика** и **интеграции** — независимые тумблеры.
- **Условная навигация:** способ терапии меняет подпись/иконку таба «Инсулин» и его содержимое;
  тип мониторинга меняет таб «НМГ/МГ», его экран и набор уведомлений.
- **Тап-фидбэк:** `-webkit-tap-highlight-color: transparent`, вместо него — hover/press-тинт из акцентной шкалы.
- **Фокус клавиатуры** (для web-реализации): `outline: 2px solid var(--color-accent); outline-offset: 2px`.
- **Скроллбары скрыты** во всех скроллируемых областях.
- **Минимальная зона нажатия — 44pt** для всех интерактивных элементов.
- **Пустые состояния:** «Ничего не найдено» в поиске; экран-заглушка с иконкой `ph-flask` для нереализованных разделов.

## Design system notes
Приложение построено на дизайн-системе **Nocturne** (см. `design/_ds/.../readme.md`):
низкая насыщенность вне акцента, тёмная база, Inter 500 для заголовков, радиус 8px в базе
(в мобильном приложении радиусы увеличены до 14–20px под тач-интерфейс), outlined-кнопки вместо залитых,
никакого чистого чёрного и белого, никаких стеков теней. Семантические цвета данных (`--c-*`) — расширение
системы под предметную область; они добавлены поверх токенов Nocturne и должны переехать в тему приложения как есть.
